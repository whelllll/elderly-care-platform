# 社区居家养老智慧服务平台 · 成员4

## 健康监测与应急响应（M4）数据库设计

> **3 张表 / 32 个字段 / 5 条外键 / 3 个视图 / 3 个存储过程 / 5 条复杂查询 / 每表 20 条测试数据**

本仓库是课程设计“社区居家养老智慧服务平台”成员4 负责的 **4.4 健康监测与应急响应（M4）** 部分，包含 E-R、数据字典、逻辑与物理设计、建表/索引 SQL、视图、存储过程、复杂查询和测试数据。

## 1. 模块范围

| 表 | 中文名 | 字段数 | 主键 | 作用 |
|---|---|---:|---|---|
| `monitor_device` | 监测设备表 | 10 | `device_id` | 设备与老人的绑定区间 |
| `vital_sign` | 体征数据表 | 9 | `vital_id` | 一行一个体征指标 |
| `emergency_event` | 应急事件表 | 13 | `event_id` | 事件登记、响应、闭环 |

- 本模块 **3 张表、32 个字段**；`elder_profile` 是成员1 的表，M4 只外键引用，不建该表。
- 跨模块外键：`elder_id → dbo.elder_profile(elder_id)`、`responder_id → dbo.sys_user(user_id)`。
- 审计字段 `created_at`、`updated_at` 由默认值/触发器或应用维护，E-R 图未展开。

## 3. 快速开始

1. 先准备 `dbo.elder_profile`（成员1）和 `dbo.sys_user`（公共账号表）。
2. 在测试库执行 `sql/01_schema.sql`（3 张表 + 7 条显式索引）。
3. 执行 `sql/02_views_procedures.sql`（3 个视图 + 3 个存储过程）。
4. 执行 `sql/04_test_data.sql`（三表各 20 条，测试库执行）。
5. 执行 `sql/03_queries.sql` 查看 5 条复杂查询结果。

> `01_schema.sql` 开头会检查 `elder_profile`、`sys_user` 是否存在；缺表会 `THROW` 并停止。
