## 首次报错及处理

首次尝试库：`Codex_FullStructure_20261120_011651_518731`。准确文件04_M3_SchemaValidation.sql，批次1（源批次开始行1），读取sys.identity_columns的seed_value结果列时，Python/ODBC返回HY106：ODBC SQL type -150 is not yet supported，column-index=2。
