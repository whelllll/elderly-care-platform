# 成员3 护工与排班管理

## 已确认接口

护工org_id引用成员1公共service_org.org_id，公共表不由成员3创建。资质唯一约束为UNIQUE(caregiver_id, certificate_no)，同一护工同一证书仅对应一个服务项目。成员2使用service_item.status，派单显式保存schedule_id；容量直接按班次统计，工时班次须与派单一致。

## 执行顺序

在选定的专用用户数据库执行01，再执行03；04可先核对内部结构。成员1与成员2真实父表就绪后执行02并落实成员2反向外键，随后将04的跨模块严格检查开关置为1复核。已有对象时脚本报错停止，不删除或覆盖现有数据。详细依赖及限制以[SQL说明](sql/README.md)为准。
