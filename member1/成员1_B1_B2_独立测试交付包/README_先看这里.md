# 成员1 B1/B2 独立测试交付包

本目录用于归档成员1负责的 B1（新增15家机构）和 B2（新增16位老人、20条能力评估、20份照护计划、20条计划明细）独立测试材料。

## 重要提醒

- 本轮实际测试数据库：`M1_B1_B2_Independent_Test`。
- 该数据库是本地独立测试库，不是项目负责人部署的正式 Data 库。
- B1、B2 已经在独立测试库中执行并通过本轮截图所示的结果核验。**不要在当前已经写入的测试库中再次执行写入脚本。**
- `sql/01...B1...安全归档版.sql` 和 `sql/02...B2...安全归档版.sql` 的写入开关均为 `0`，用于安全归档和代码追溯。
- B2 实际执行版本另存于 `evidence/sql_实际执行留档/`，其中写入开关为 `1`，仅用于追溯，文件名已标注“勿重跑”。
- B1 保存来源文件的写入开关为 `0`；结果截图证明B1新增15家成功，但无法仅凭保存文件还原当时编辑器中的开关值。因此归档的是安全副本，不宣称它与运行时编辑器内容逐字节一致。
- 本交付包不包含数据库 `.bak` 备份，也不包含正式 Data 库连接凭据。

### `docs/`

- `01_B1_B2独立测试报告.md`：本轮测试结果和业务口径。

- `03_提交给项目负责人的说明.md`：本轮工作范围、测试结论和后续整合说明。

另在 `sql_实际执行留档/` 子目录中保存B2实际执行版本，仅供追溯，**不要重新执行**。

## 建议阅读顺序

1. 先阅读 `docs/01_B1_B2独立测试报告.md`。
